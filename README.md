# JDDP-UAM

This repository contains the data and code accompanying the JDDP-UAM paper.

[Download the data and code (ZIP)](https://github.com/121121-luan/JDDP-UAM/raw/refs/heads/main/JDDP-UAM.zip)

Extract the ZIP file to access the six-node and thirty-node datasets,
the ALNS-CG code, and the CPLEX exact MILP code.
